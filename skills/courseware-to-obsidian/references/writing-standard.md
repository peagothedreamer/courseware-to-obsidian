# 专业写作规范

这份规范替代按专业维护的词典。无论课件属于哪个学科，都按同一套标准写“像这门课的专业笔记”，而不是把幻灯片标题抄成 Markdown。

## 1. 术语

- 首次出现的关键术语用 `**术语**` 标出；课件给了英文、缩写或符号时一并保留，例如 `**焓**（enthalpy，$H$）`。
- 同一概念全文只用一种叫法。课件前后用词不一致时，选更标准的那个，另一种在首次出现处注明。
- 不把口语化说法当术语；课件里的比喻只用于解释，不替代定义。

## 2. 符号与公式

- 符号以课件为准；课件缺失或乱码时，采用该学科的标准写法。
- 行内公式用 `$...$`，独立公式用 `$$...$$`。公式前后要有文字说明它描述什么。
- 表格单元格里的公式不能出现裸 `|`，用 `\mid`、`\lvert ... \rvert`。
- 公式里的每个新符号，第一次出现要给出含义；符号表用表格集中列。

## 3. 结构与深度

每个 `###` 子主题优先按这个顺序组织（按内容取舍，不硬凑）：

1. **定义/对象**：是什么，适用范围。
2. **性质/条件**：成立条件、前提、分类。
3. **关系/推导**：公式、步骤、因果链。
4. **例子/应用**：课件例题或典型场景。
5. **易错点**：只在课件明确提示或确有常见误区时写 `> [!warning]`。

要求：

- 不只写“是什么”，至少回答一个“为什么”或“怎么用”。
- 推导写关键步骤和每一步的依据，不跳步。
- 对比用表格；流程用有序列表；分类用列表。
- 过程、对比、算例类重难点主动自绘图解：表格、代码块、ASCII 或 LaTeX 排版。先问“最难的概念能不能看图理解”，不能就画。
- 一节的要点应能脱离课件复述；复述不了的句子删掉或补全。

## 4. 语言

- 短句，一句话说一件事。
- 陈述事实，不用“我们可以看到”“众所周知”等填充语。
- 中文术语与英文缩写之间留空格（`Transformer 模型`），公式与中文之间按 Markdown 习惯排版。
- 不写大段散文；能用表格/列表/公式表达就不用段落。

## 5. 诚实边界

- 只写课件讲过的内容。课件没给的结论、数据、推导，不补。
- 课件内容无法辨认时，写“课件此页为图片/无法辨认”，或截图，不要猜。
- 不确定的地方用 `> [!note] 课件未明确说明……` 标出，不混进确定结论，并报告给用户。
- 引用课件的例题、练习题（含自测题）时，先完整抄录题面（题干、条件、选项、题图），再给解答。只给答案、只概括题意、把细节写成“略”都不合格。

## 6. 写完自检

- 每个 `###` 是否都有可复述的要点，而不是标题党？
- 术语、符号、单位是否全文一致？
- 公式是否解释了符号和适用条件？
- 表格是否比段落更清楚？有没有该用表格却写成散文的地方？
- 最难的概念有没有图？过程、对比、算例是否自绘了解释图？
- 每道题是否带完整原题，而不是只有答案或一句概括？
- 有没有编造课件没讲的内容？
